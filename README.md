# AutoShoter

Периодические скриншоты экрана или отдельного окна на macOS: выбрал, как часто
снимать и когда остановиться, — приложение само складывает кадры в папку.

Нативное приложение: SwiftUI + ScreenCaptureKit, без сторонних зависимостей.

## Что умеет

| Возможность | Где |
|---|---|
| Снимок раз в N секунд/минут | «Как часто», пресеты 10 с … 15 мин |
| Пауза без закрытия сессии | Кнопка «Пауза» — папка и нумерация снимков сохраняются |
| Длительность сессии | Счётчик в нижней панели, время на паузе не считается |
| Автостоп: после N снимков, через время, в заданное время | «Когда остановиться» |
| Съёмка экрана или конкретного окна | «Что снимаем» |
| Исключить собственное окно из кадра | «Что снимаем» (только для экрана) |
| Курсор в кадре | «Что снимаем» |
| Своя папка AutoShoter внутри выбранной | «Куда сохраняем», включена по умолчанию |
| Папка на каждый день и на каждую сессию | «Куда сохраняем» |
| Формат JPEG / HEIC / PNG | «Качество и вес» |
| Ползунок качества и масштаб 100 / 75 / 50 / 25 % | «Качество и вес» |
| Вес одного снимка, за час и за всю сессию | «Качество и вес» — делается пробный кадр текущими настройками |
| Управление из строки меню | значок камеры справа вверху |

## Требования

- macOS 14 или новее
- Xcode или Command Line Tools (`xcode-select --install`) — для сборки

## Сборка и запуск

```bash
./build.sh            # собрать в build/AutoShoter.app
./build.sh install    # собрать и положить в ~/Applications
./build.sh run        # собрать и запустить
```

### Первый запуск

macOS спросит доступ к записи экрана — его нужно выдать:
**Системные настройки → Конфиденциальность и безопасность → Запись экрана → AutoShoter**.
После этого нажмите «Обновить» в приложении.

### Подпись

`build.sh` подписывает приложение локальным сертификатом «AutoShoter Local
Signing». Он нужен, чтобы требование подписи не зависело от хэша бинарника —
иначе macOS после каждой пересборки считает приложение новым и сбрасывает
разрешение на запись экрана.

Если сертификата в связке ключей нет, сборка подписывается ad-hoc и разрешение
будет слетать. Создать сертификат:

```bash
./setup-signing.sh
```

Пароль от Mac не нужен: настройки доверия не меняются, `codesign` работает и с
недоверенным сертификатом.

Если разрешение всё-таки слетело и macOS перестала показывать запрос — удалите
AutoShoter из списка «Запись экрана» кнопкой «−» и запустите приложение заново.

## Остановка сессии

Четыре режима в разделе «Когда остановиться»:

- **Не останавливаться** — пока не нажмёте «Остановить».
- **После N снимков** — счётчик.
- **Через время** — N минут чистой съёмки; время на паузе не засчитывается.
- **В заданное время** — например до 15:00. Если это время сегодня уже прошло,
  сессия закончится завтра. Момент фиксируется на старте и не плывёт.

Во всех режимах со сроком приложение не делает лишний кадр «через дедлайн»:
если следующий снимок попадает за границу, оно досыпает до неё и останавливается.

Под настройками показан прогноз: сколько выйдет снимков, а в разделе
«Качество и вес» — сколько это займёт места.

## Пауза

«Пауза» — это не остановка: сессия остаётся открытой, папка та же, нумерация
продолжается с того же места. Длительность сессии на паузе не растёт, поэтому
режим «через время» считает именно съёмку. Кнопка есть и в меню строки статуса.

## Куда попадают файлы

```
~/Pictures/                       ← выбранная папка
└── AutoShoter/                   ← если включена «Своя папка AutoShoter»
    └── 2026-09-21/               ← если включена «Папка на каждый день»
        └── 14-30-05 Созвон/      ← если включена «Папка на каждую сессию»
            ├── shot_0001_14-30-05.jpg
            ├── shot_0002_14-31-05.jpg
            └── …
```

Все три уровня отключаются независимо. Если снять все галочки, файлы лягут
прямо в выбранную папку. Папка AutoShoter нужна, когда базовой выбрано что-то
общее вроде «Загрузок»: без неё папки с датами лягут туда россыпью.

## Как устроено

```
Sources/AutoShoter/
├── AutoShoterApp.swift         точка входа, окно, меню в статус-баре
├── Support/
│   ├── AppSettings.swift       все настройки + сохранение в UserDefaults
│   ├── ImageFormat.swift       JPEG / HEIC / PNG
│   └── StopMode.swift          условия остановки, прогноз, форматирование времени
├── Core/
│   ├── ScreenCatalog.swift     список экранов и окон, SCContentFilter, права
│   ├── Capturer.swift          один кадр через SCScreenshotManager
│   ├── ImageEncoder.swift      CGImage → Data нужного формата и качества
│   ├── StorageLayout.swift     правила именования папок и файлов
│   ├── SessionController.swift цикл съёмки, пауза, условия остановки, журнал
│   └── PreviewEstimator.swift  пробный кадр для оценки веса
└── UI/                         секции интерфейса
```

## Планы

Выгрузка снимков на FTP/SFTP. Точка подключения уже есть: в
`SessionController.shoot()` файл к этому моменту записан на диск, туда же
ставится вызов аплоадера. Системный `curl` умеет `ftp` и `ftps`, но не `sftp` —
для SSH понадобится `/usr/bin/sftp` с ключом.
